# Ohs Events

Events with attendees and car bookings, calendars.

Hubleto app of the Ohs set (occupational health service, Slovakia). Namespace: `Hubleto\App\External\WaiBlue\OhsEvents`.
Needs: `wai-blue/hubleto-ohs-core`.

## Install into a Hubleto project

```bash
composer config repositories.wai-blue/hubleto-ohs-events vcs <repository-url>
composer require wai-blue/hubleto-ohs-events:dev-main
php hubleto app install "Hubleto\App\External\WaiBlue\OhsEvents"
npm run build
```
